Installation guide

  1. Step 1

    Download the "native" Sandstorm EQOA client here.

  2. Step 2

    Put the downloaded file in a folder of its own (the client keeps a couple of small files next to it when it updates itself).

  3. Step 3

    Choose your disc image (downloaded above). The first time it starts, the client opens a file dialog and asks for your Frontiers ISO. It can have any name and be in any folder. The client remembers where it is, so after this it starts straight into the game. (To switch to another image later, drop the ISO onto the program, or start it with the ISO's path as an argument.)

  4. Step 4

    Enter the server address via the title screen. Choose Network Setup and type the server address: "eqoa.live".

  5. Step 5

    Choose Play. On the login screen, pick Create User Name to make a new Sandstorm account, or log in with one you already have. Save Account remembers your name and password for next time. Then pick the server from the list, choose or create a character, and you're in Tunaria.
